
# 💳 Razorpay Clone

A modern and responsive Razorpay website clone built using **HTML5, Tailwind CSS, JavaScript, and Vite**. This project recreates the look and feel of Razorpay's website with a clean user interface, attractive layouts, smooth hover effects, and responsive design.

## 🚀 Live Demo

🔗 [View Live Website](#)


## ✨ Features

- Modern and clean user interface
- Fully responsive design
- Attractive navigation bar
- Stylish landing page sections
- Smooth hover and transition effects
- Custom typography using Google Fonts
- Mobile-friendly layouts
- Reusable styling with Tailwind CSS

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- Vite
- Google Fonts
